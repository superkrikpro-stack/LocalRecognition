# LocalRecognition — локальный голосовой ассистент с интеграцией в 1С

## Идея
Полностью локальная система голосового управления:
распознавание речи → LLM-обработка → выполнение действия в 1С / ОС / браузере → озвученный ответ.
Без облачных сервисов.

## Стек
- **ASR**: VOSK (русская модель)
- **LLM**: Ollama (qwen2.5:1.5b)
- **TTS**: Silero (Python-сервер)
- **Сервер**: Java (Swing), HTTP API на порту 8000
- **Аппаратный клиент**: ESP32-S3, стерео INMP441, OLED SSD1306
- **Интеграция**: 1С 8.3, HTTP-сервисы, фоновые задания, ffmpeg

## Архитектура
ESP32 (захват аудио + VAD) → POST /recognize → Java-сервер →
Ollama (разбор команды) → SkillExecutor (действие в ОС/1С/браузере) →
TTS-ответ → SoundPlayer в 1С

## Что реализовано в 1С
- Фоновое распознавание с опросом статуса и таймаутом
- Очередь файлов с автоповтором по ошибкам
- Автоопределение устройства записи (ffmpeg -list_devices)
- Команда «Сказать» — голосовой ввод с любой формы конфигурации
- Панель статуса сервера (опрос /logs каждые 10 сек)
- Озвучка ответа через PowerShell / SoundPlayer
